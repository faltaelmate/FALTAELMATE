# Falta el Mate — sitio web editable

Este sitio está hecho en HTML + CSS + JavaScript y funciona sin instalar nada.

## Cómo abrirlo
1. Descomprimí el archivo ZIP.
2. Entrá a la carpeta `falta_el_mate_web`.
3. Hacé doble clic en `index.html`.
4. Se abrirá en Chrome, Edge o Firefox.

## Cómo editarlo gratis
La opción más sencilla es **Visual Studio Code** (gratis).
- Abrí la carpeta completa en Visual Studio Code.
- Editá `index.html` para cambiar textos.
- Editá `styles.css` para colores, tamaños y diseño.
- Editá `script.js` para funciones.
- Reemplazá las imágenes dentro de `assets` si querés poner tus propias fotos.

También podés editar los archivos con el Bloc de notas de Windows.
